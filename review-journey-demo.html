🗺️ The Step-by-Step User Journey

Here is the exact timeline of events experienced by a user from the moment they visit the app to storing their review in the database:

1

User Opens Contact Drawer

User clicks the clean "Contact" link with the mail icon in the top-right header. The Depth Parallax drawer smoothly slides in from right to left.

2

User Rates the App

User views Section 3: "Rate this app / Tell others what you think". Hovering over stars dynamically paints them in golden yellow (#fbbc04). User clicks on a star (e.g. 5 Stars) or taps "Write a review" (blue #1a73e8).

3

Review Input Box Reveals

The selected variation animates smoothly into view. The input box is revealed with rounded border, placeholder Describe your experience (optional), and character counter 0/500.

4

User Types Their Feedback

As the user types, the character counter updates live (e.g. 42/500). If the user types beyond 450 characters, the counter shifts to an alert tone to warn of the 500-character ceiling.

5

User Clicks "Post"

The "Post" button initiates an asynchronous submission to the database. The client validates the payload and writes the record.

6

Instant Confirmation & Persistence

The user sees a reassuring green confirmation message: ✓ Thank you! Your review has been submitted. The rating is also saved locally in localStorage so returning users see their active rating preserved.

🗄️ Database Architecture & Column Specification

To allow you to easily view, manage, and export user reviews, here are the exact columns we collect and the recommended database engines:

🚀 Supabase (Recommended)

Instant PostgreSQL database with a built-in web dashboard (like Airtable/Excel) where you can view every review in real-time. Free tier supports 500,000 rows.

🔥 Firebase Firestore

Google Cloud serverless NoSQL document store. Zero config, real-time sync, and a generous free tier of 50,000 reads/writes per day.

📊 Google Sheets API

Appends every review as a new row in a private Google Sheet in your personal Google Drive. 100% visual and easily shareable without developer tools.

Recommended SQL Schema (PostgreSQL / Supabase):

-- Table: app_reviews CREATE TABLE app_reviews ( id UUID DEFAULT gen_random_uuid() PRIMARY KEY, rating SMALLINT NOT NULL CHECK (rating >= 1 AND rating <= 5), review_text VARCHAR(500), character_count INTEGER DEFAULT 0, app_version VARCHAR(10) DEFAULT 'v1.2.0', device_type VARCHAR(20), -- 'desktop' | 'mobile' | 'tablet' created_at TIMESTAMPTZ DEFAULT NOW(), status VARCHAR(20) DEFAULT 'published' ); -- Index for fast analytics queries CREATE INDEX idx_reviews_rating ON app_reviews (rating); CREATE INDEX idx_reviews_created ON app_reviews (created_at DESC);
