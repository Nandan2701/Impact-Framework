🚀 The Complete User Journey

How the user experiences the entire review flow:

  1. Intent Trigger: User clicks any star or "Write a review" in Section 3.
  2. Instant Reveal: Stars highlight in golden yellow (`#fbbc04`), and the review box smoothly reveals according to the selected variation.
  3. Typing & Live Counter: The box displays Describe your experience (optional) with real-time 0/500 tracking.
  4. One-Click Post: User taps "Post" -> payload is validated and submitted to the database asynchronously.
  5. Optimistic Confirmation: User receives immediate visual confirmation (✓ Thank you for your review!) without page reload.
